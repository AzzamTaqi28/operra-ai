# Operra v0.1.0

Release date: unreleased public OSS launch

Operra v0.1.0 is the first public release focused on AI-assisted Purchase Request approval.

## Highlights

- Multi-tenant organization setup
- Users, departments, and roles
- JSON-first workflow configuration
- AI-assisted workflow generation
- Purchase request drafting and submission
- Role-based approvals
- Comments and attachments
- Audit logs
- CSV exports
- Next.js web app
- Docker Compose deployment

## Included Docs

- Product requirements and architecture
- API contract and workflow engine
- Security, testing, UI, and deployment guidance
- Public roadmap, workflow chart, contribution guide, support, security policy, changelog, and code of conduct

## What This Release Is Not

- Full procurement suite
- Purchase orders or payments
- Visual drag-and-drop workflow builder
- Multi-organization user switching
- Autonomous AI agents

## Notes

- Workflow execution is deterministic.
- AI can generate workflow JSON, but the backend validates and controls execution.
- Attachments use S3-compatible storage with MinIO for local/self-hosted deployment.
- Attachment downloads use authenticated backend streaming in v0.1.
- Audit logs and CSV exports are part of the core product flow.
