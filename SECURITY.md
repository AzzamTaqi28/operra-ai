# Security Policy

Operra handles sensitive approval, attachment, and audit data. Security issues
should be reported privately.

## Reporting vulnerabilities

Use GitHub Security Advisories for the repository if available.

If advisories are not available, contact the maintainers through the private
security contact listed on the release page or project website.

Do not post vulnerability details in public issues.

## What to include

- A short summary of the issue
- The affected component or endpoint
- Reproduction steps
- Any relevant logs or screenshots
- Your preferred contact method

## Safe disclosure

- Allow time for review and remediation before public disclosure.
- Avoid sharing exploit details publicly until a fix is available.
- Do not include secrets, tokens, or customer data in reports.
